# Rosewood Engine

Rosewood Engine is a specialized framework and engine built on top of Next.js, designed for rapid development of data-driven, interactive applications.

## Key Features

- **Component-Driven:** Built using modern React patterns.
- **Strict Styling:** Adheres to the "NewOS Minimal Stark" design philosophy (see `docs/UI_UX_DIRECTIVE.md`).
- **Engine-Powered:** Features specialized pipelines for data ingestion and compilation.

## Getting Started

1.  **Clone the Repository**
2.  **Install Dependencies**
    ```bash
    npm install
    ```
3.  **Run Development Server**
    ```bash
    npm run dev
    ```
4.  **Open Browser**
    Navigate to [http://localhost:3000](http://localhost:3000).
